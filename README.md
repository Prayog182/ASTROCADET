# ASTROCADET – Junior Astronaut Mission Trainer

## About the Project
ASTROCADET is an educational simulation game that introduces users to the challenges of managing resources during a space mission.

Players manage essential resources such as oxygen, water, food, power, and radiation while making decisions to keep their mission running.

## Project Versions

- **C++ Version:** A command-line astronaut mission simulator.
- **Browser Version:** A browser-based version using HTML, CSS, and JavaScript.

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- Visual Studio Code

## NASA Data

NASA DONKI (Space Weather Database) solar flare data was downloaded and explored as part of this project. The current simulation uses simplified educational values and does not represent actual astronaut radiation exposure.

## Project Versions

ASTROCADET has two separate implementations:

**1. C++ Command-Line Version**
The original version was developed using C++. It runs in the terminal and includes seven-day astronaut missions, resource management, emergency events, difficulty levels, scoring, and mission debriefing.

**2. Browser-Based Version**
A separate browser version was developed using HTML, CSS, and JavaScript. It runs directly in a web browser and is published using GitHub Pages.

**Important:** The browser version does not execute the C++ code. Both versions are separate implementations of the ASTROCADET educational mission simulation.
