# ASTROCADET – Junior Astronaut Mission Trainer

## About the Project
ASTROCADET is an educational simulation game that introduces users to the challenges of managing resources during a space mission.

Players manage essential resources such as oxygen, water, food, power, and radiation while making decisions to keep their mission running.

## Project Versions

- **C++ Version:** A command-line astronaut mission simulator.
- **Browser Version:** A browser-based version using HTML, CSS, and JavaScript.

## Technologies Used

- C++
- HTML
- CSS
- JavaScript
- Visual Studio Code

## NASA Data

NASA DONKI (Space Weather Database) solar flare data was downloaded and explored as part of this project. The current simulation uses simplified educational values and does not represent actual astronaut radiation exposure.

## Project Structure

- `cpp-version/` – C++ source code.
- `browser-version/` – Browser version files.
- `presentation/` – Project presentation slides.
- `nasa-data/` – Downloaded NASA data.

## How to Run

### C++ Version
1. Open the C++ source file in Visual Studio Code.
2. Compile using a C++ compiler.
3. Run the program.

### Browser Version
1. Open the `browser-version` folder.
2. Open `index.html` in a web browser.
